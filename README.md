# TikTokWid — Botanical Editorial

Набор виджетов для TikTok LIVE Studio / OBS в стилистике: тёмный лесной зелёный, оливка, антикварная латунь, угольный, тёплый кремовый, плёночное зерно.

- likes.html   — счётчик лайков и цель
- socials.html — соцсети (список или по кругу)
- plant.html   — растущее растение
- studio.html  — пульт управления (открывать на ПК или телефоне)
- index.html   — редактируемая плашка с ником

Как пользоваться: открой studio.html, скопируй ссылки виджетов и вставь их в Link в TikTok LIVE Studio.
Логика, настройки и ссылки работают как раньше.
